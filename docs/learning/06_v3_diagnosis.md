# v3实验怎样理解

先问“分数在量什么”，再问“改动有没有帮助”。文字F1量参考表达重合，语义相似度量意思接近，两者都不是事实正确率。RAG还要看必要信息是否回答、原文是否支持、引用是否对应，以及材料不足时是否合理拒答。

本轮先重算旧答案，再在固定开发问题上改变提示、重排或打包。所有失败保留，没有把失败样本删除后重算更高分。题目和论文互斥的新H_QA200封存，不能用它挑配置。

工作流分类和检索器分类不同。“比较”需要找齐双方、按相同维度组织证据；“总结”需要覆盖重要章节。分类器准确也不保证这些动作有效。现有工作流开发映射没有超过固定策略，比较/总结可靠标签不足，因此不训练新分类器。

LoRA不保证提升。训练材料与实际检索材料差异、拒答策略和答案长度都能改变结果。本次监督链路可更新与恢复；合并数值门槛未过。不能把loss下降或代码支持训练写成泛化收益。

180次在线实验每次重新编码问题，真实检索、打包、生成。两策略的P50几乎相同，core-first的P95更慢；开缓存的单独应用测试不证明模型推理加速。

没有候选通过开发门槛，默认保留v2。正式留出配对及部分事实评分受阻，所以执行完整性与工程流程结束必须分开填写。报告中的UNKNOWN、BLOCKED、NOT_REVIEWED是结论的一部分。
