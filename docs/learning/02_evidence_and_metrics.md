# 证据和指标：命中论文不等于找到答案

检索到正确论文，只能说明文档级命中。论文可能很长；问题的答案在实验部分，模型却只看到摘要，此时文档命中为 1，实际证据覆盖可能为 0。两者必须分开报告。

本项目的坐标是清洗后的规范化全文坐标（canonical），使用左闭右开区间。教学例子：证据单位占 `[100,200)`，实际发送 `[100,150)`，则连续覆盖是 0.5，完整证据单位召回是 0。若又发送 `[140,200)`，重叠先合并为 `[100,200)`，覆盖是 1，而不是把两段相加得到 1.1。这些数值是教学例子，不是实验结果。

若一个参考答案需要两个段落，两个段落都完整覆盖，完整参考证据集合才记 1。不同标注者可以给出不同合法证据集合；v2 对每个集合单独计算，并按“完整集合 → 完整单元 → 连续覆盖”的固定顺序选最好合法集合，平局按原标注顺序。规则写在 `ragscope/evaluation/evidence.py`，不能看到某个配置表现差就换规则。

三种答案文字指标：

- EM（Exact Match）看规范化后是否完全一致。
- token F1 看预测与参考的词频重合，兼顾漏词和多词。
- ROUGE-L 看词序列的最长共同子序列。v2 使用与 EM/F1 相同规范化、无词干化的词级 LCS F1；旧 scorer 采用 stemming，旧表不能直接混合比较。

多个合法答案都参与评分，各指标取最佳匹配。yes/no、抽取片段与自由文本分别转换成参考文本。文字重合是正确性的代理指标，不能证明所有事实正确。中文夹具用于边界与功能测试；本轮没有中文真实质量基准时，不宣称中文质量已验证。

不可回答题相对于指定论文定义；它不等于整个互联网都没有答案。证据覆盖和答案文字重合为 N/A，拒答另计 precision、recall、F1。可回答题的错误拒答记失败；timeout、OOM、解析失败仍保留在冻结总样本中。总体均值与“成功请求条件下”的均值分开展示，后者不能替代前者。

JSON 合法率、引用 ID 可见率、答案含引用率、引用金标准证据覆盖是不同指标。一个 ID 真实存在，只能说明引用合法，不能自动证明该段支持每一个答案陈述。因此这些指标不改名为 faithfulness 或“无幻觉率”。

同一篇论文的几个问题不是独立抽样。`ragscope/evaluation/v2.py` 按论文整体重抽 2000 次，给出 95% cluster bootstrap 区间；配对比较必须保留同样的 query IDs，包括失败。区间不是保证，新方法无提升也必须报告。

实际证据链：逐条 JSONL → `.config.json` → 配置哈希和记录哈希 → 汇总。离线回归见 `tests/unit/test_metrics_v2.py`；本模块与生成测试合计 50 项通过、97% 行覆盖，证据在 `D:/RAGScope_Runtime/runs/generation_coverage.json`。这些是软件测试结果，不是模型得分。

协议v2.2的引用ID可见率受每次请求的可见ID枚举schema约束。它用于确认实现正确性，不用于证明答案受证据支持，也不能作为faithfulness提升。真正的支持性代理只看回答陈述与实际引用片段，仍可能给出unsupported/unknown；人工复核导出字段初始保持NOT_REVIEWED。
